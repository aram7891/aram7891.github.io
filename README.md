## Estructura del Proyecto

- `/content/essays` → Ensayos en PDF (español e inglés)
- `/sections` → Fragmentos HTML modulares reutilizables
- `/styles` y `/js` → Estilos y scripts
- `/api` → Funciones serverless (Vercel)
- `/tools` → Herramientas internas de creación de contenido
- `/archive` → Experimentos y versiones anteriores
- `/books`, `/protocolo`, `/selfloveclub` → Secciones activas del sitio

## Despliegue

El proyecto se despliega principalmente en **Vercel**.
